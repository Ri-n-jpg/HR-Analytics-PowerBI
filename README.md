# HR Analytics Dashboard

## 📊 Project Overview

The HR Analytics Dashboard is an interactive data analytics project developed using Microsoft Power BI. The project analyzes employee data to provide insights into workforce demographics, employee distribution, promotion status, service status, and retrenchment trends.

The dashboard transforms raw HR data into meaningful insights using data cleaning, data transformation, data modeling, DAX calculations, and interactive visualizations.

## 🎯 Project Objectives

* Analyze overall employee workforce
* Understand male and female employee distribution
* Analyze employee promotion status
* Track employees due and not due for promotion
* Analyze employee service status
* Identify employees who may be retrenched
* Analyze workforce distribution across job levels
* Create an interactive dashboard for HR analysis
* Present important HR KPIs in an easy-to-understand format

## 🔄 Project Workflow

### 1. Data Collection

Imported the HR employee dataset from Excel/CSV files into Power BI.

### 2. Data Cleaning

Used Excel and Power Query to:

* Remove duplicate records
* Handle missing values
* Correct data types
* Standardize inconsistent values
* Remove unnecessary columns
* Check data consistency

### 3. Data Transformation

Used Power Query to:

* Transform columns
* Filter unnecessary records
* Create required fields
* Format data types
* Prepare the dataset for analysis

### 4. Data Modeling

Created a structured data model in Power BI to organize the HR data and support efficient analysis.

### 5. DAX Analysis

Created DAX measures to calculate important HR metrics such as:

* Total Employees
* Male Employees
* Female Employees
* Male Percentage
* Female Percentage
* Employees Due for Promotion
* Employees Not Due for Promotion
* Employees On Service
* Employees Will Be Retrenched
* On-Service Percentage
* Retrenchment Percentage

### 6. Data Visualization

Created an interactive Power BI dashboard using:

* KPI Cards
* Bar Charts
* Column Charts
* Donut Charts
* Tables
* Slicers
* Filters

## 📈 Dashboard Features

### Employee Overview

Provides an overview of the workforce using KPIs such as:

* Total Employees
* Male Employees
* Female Employees
* Male Percentage
* Female Percentage

### Promotion Analysis

Analyzes employee promotion status, including:

* Employees Due for Promotion
* Employees Not Due for Promotion
* Promotion distribution

### Service & Retrenchment Analysis

Provides insights into employee service and retrenchment status, including:

* Employees On Service
* Employees Will Be Retrenched
* On-Service Percentage
* Retrenchment Percentage

### Job Level Analysis

Analyzes employee distribution across different job levels to understand workforce structure.

### Interactive Filtering

Users can analyze the dashboard using filters and slicers based on available employee attributes such as:

* Gender
* Job Level
* Department
* Promotion Status
* Retrenchment Status
* Other employee attributes

## 💡 Key Insights

The dashboard can be used by HR teams to:

* Understand workforce demographics
* Monitor employee promotion eligibility
* Analyze employee service status
* Identify retrenchment-related workforce trends
* Compare employee distribution across job levels
* Support data-driven HR decision-making
